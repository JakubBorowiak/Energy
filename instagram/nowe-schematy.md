# 14 nowych schematów tweet-postów (jeszcze nietestowanych na profilu)

Każdy schemat testuj 2–3 razy, zanim go ocenisz – jeden post to jeszcze nie dane.

## Pewniaki – mocne dowody z innych formatów

### 1. „Nie spodoba Ci się to, co powiem”
Dowód: karuzela z tym hookiem („…Jeśli ktoś krzyczy, to dlatego, że mu na to pozwoliłaś”) zrobiła 44,8k, a Twoje karuzele zwykle 3–7k. Do tego mechanizm plus wpływ działa w tweetach (57–76k).
```
Nie spodoba Ci się to, co powiem:
Ludzie nie przekraczają Twoich granic przez przypadek.
Robią to, bo sprawdzili, że mogą.
```
```
Nie spodoba Ci się to, co powiem:
Każde „tak” wbrew sobie to też była decyzja.
Twoja.
```

### 2. Mini-dialog: zdarta płyta w akcji
Dowód: „Powtórz dokładnie to samo zdanie” zrobiło 46k, ale jako rada. Tu pokazujesz to od razu jako scenkę.
```
– Wpadniesz w sobotę?
– Nie dam rady.
– A co robisz?
– Nie dam rady.
– No ale chociaż na godzinkę?
– Nie dam rady. Bawcie się dobrze!

Zero tłumaczeń. Zero kłótni.
```

### 3. Słabo ❌ / Mocno ✅: to samo zdanie w dwóch wersjach
Dowód: reelsy w formacie „Słaba komunikacja / Trener komunikacji” zrobiły 877k, 67k i 46k. W tweetach tego formatu jeszcze nie było.
```
Słabo ❌:
„Przepraszam, ale chyba raczej nie dam rady, bo mam teraz dużo na głowie i…”

Mocno ✅:
„Nie dam rady.”
```
```
Słabo ❌:
„Mógłbyś może trochę mniej krzyczeć?”

Mocno ✅:
„Nie rozmawiam, kiedy krzyczysz.”
```

### 4. Zamiast… powiedz…
Dowód: reelsy „Przestań używać tego słowa” (76k) i „Te 3 słowa wywołują kłótnię” (34k).
```
Zamiast: „Przepraszam, że zawracam głowę”
Powiedz: „Masz chwilę?”

Zamiast: „Przepraszam za spóźnienie”
Powiedz: „Dziękuję, że poczekałaś”

Zamiast: „Sorry, że tyle gadam”
Powiedz: „Dzięki, że mnie wysłuchałaś”
```

### 5. Gotowiec do skopiowania (SMS lub wiadomość)
Dowód: wygrywa gotowe zdanie, a duża część odmów dzieje się dziś przez telefon. Takie posty ludzie zapisują i wysyłają dalej.
```
Gotowa wiadomość, gdy nie chcesz iść, a nie wiesz, jak odmówić:
„Dzięki za zaproszenie! Tym razem mnie nie będzie, ale bawcie się świetnie 🙂”
Skopiuj. Wyślij. Odłóż telefon.
```
```
Gotowa wiadomość do kogoś, kto nie oddaje pieniędzy:
„Hej, przypominam o 200 zł. Do kiedy mogę się spodziewać zwrotu?”
Bez przepraszania. Bez „wiem, że masz ciężko”.
```

## Solidne – logika z danych, format nowy

### 6. Słownik zdań, które mają Cię uciszyć
Dowód: mechanizm działa (73–76k), reelsy o manipulacji zrobiły 23–39k. Post odsłania, co się kryje za zdaniem.
```
Słownik zdań, które mają Cię uciszyć:
„Przesadzasz” = „Nie chcę się zmierzyć z tym, co zrobiłem.”
„Żartowałem” = „Sprawdzałem, ile mi wolno.”
„Po tym wszystkim, co dla Ciebie zrobiłam?” = „Wystawiam Ci rachunek.”
```

### 7. Test reakcji: kto Cię szanuje, a kto korzystał
```
Mówisz „nie”.
Osoba, która Cię szanuje: „Jasne, rozumiem.”
Osoba, która korzystała z Twojego „tak”: „Co się z Tobą stało?”
Ich reakcja mówi o nich. Nie o Tobie.
```

### 8. Drabina 1–2–3: co robić, gdy granica nie działa za pierwszym razem
```
Ktoś przekracza Twoją granicę.
1. raz – mówisz spokojnie, co Ci nie pasuje.
2. raz – powtarzasz to samo zdanie.
3. raz – kończysz rozmowę.
Bez krzyku. Bez czwartej szansy.
```

### 9. Nazwana zasada
Zasady z nazwą łatwo zapamiętać i łatwo je udostępnić („Zasada jednego zdania” już jest na liście).
```
Zasada 24 godzin:
Na każdą prośbę, przy której ściska Cię w brzuchu, odpowiadasz dopiero jutro.
Dzisiejsza Ty chce być miła. Jutrzejsza Ty powie prawdę.
```

### 10. Szablon z lukami do wypełnienia
```
Szablon na trudną rozmowę. Zapisz:
„Kiedy ___,
czuję ___.
Potrzebuję ___.”

Np.: „Kiedy komentujesz moje jedzenie przy wszystkich, czuję się upokorzona. Potrzebuję, żebyś przestał.”
```

## Eksperymenty – mniej dowodów, ale warto sprawdzić

### 11. Pakiet „3 zdania, gdy…”
Listy w reelsach robiły 15–18k, ale lista samych gotowych zdań w tweecie nie była jeszcze testowana. To post do zapisania.
```
3 zdania, gdy ktoś naciska po Twoim „nie”:
1. „Słyszałam. Moja odpowiedź się nie zmienia.”
2. „Rozumiem, że Ci zależy. Nadal nie.”
3. „Ten temat jest dla mnie zamknięty.”
```

### 12. Wyzwanie tygodnia
Cel: komentarze, które podbijają zasięg. Nawiązuje do 38,7k („Zacznij odmawiać w małych sytuacjach”).
```
Wyzwanie na ten tydzień:
Odmów raz. Jedno „nie”, bez ani jednego „bo”.
Napisz w komentarzu „zrobione”, kiedy Ci się uda.
```

### 13. „Gdyby to była Twoja przyjaciółka”
```
Gdyby Twoja przyjaciółka powiedziała Ci, że ktoś ją tak traktuje – co byś jej powiedziała?
No właśnie.
Powiedz to sobie.
```

### 14. Wiadomość od klientki (tylko prawdziwa!)
Społeczny dowód plus Twój autorytet trenera. Używaj wyłącznie prawdziwych wiadomości, najlepiej za zgodą i bez danych osobowych.
```
Klientka napisała mi wczoraj:
„Pierwszy raz powiedziałam mamie «nie». Świat się nie zawalił. Mama też nie.”
Za pierwszym razem jest najtrudniej.
```
